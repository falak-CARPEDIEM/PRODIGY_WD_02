## Stopwatch Web App

This project is **Task 2** of my Web Development Internship at **Prodigy InfoTech**.  
It is a modern, responsive **Stopwatch Web App** built using HTML, CSS and JavaScript.

 Live Demo

 [Open Stopwatch Web App](https://falak-carpediem.github.io/PRODIGY_WD_02/)
 
 Features:

- Start, Pause, Reset controls  
- Lap recording with lap list  
- Clear all laps button  
- Clean, dark theme UI  
- Mobile‑friendly responsive layout  
- Status line showing current state (Running / Paused / Reset)  
- Subtle glow effect when stopwatch is running
  
Tech Stack:

- **HTML5** – structure of the page  
- **CSS3** – styling, layout, responsive design  
- **JavaScript** – stopwatch logic, laps, DOM updates  
- **GitHub Pages** – hosting the live project

Project Structure:

│── index.html    # main UI

│── style.css     # styles and layout

└── script.js     # stopwatch functionality
